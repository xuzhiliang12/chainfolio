HOW TO USE CHAINFOLIO

从账户到活动，
把每个钱包管清楚。

这套系统只做两件事：先建立清晰的账户结构并掌握资金状态，再以钱包为单位管理女巫检查、活动和任务进度。

◎
只读监控只输入公开地址，不需要助记词或私钥。
⌁
按钱包记录每个钱包都有独立的检查、活动和备注。
▦
逐层汇总所有数据最终回到你的总账户看板。
01

ACCOUNT MANAGEMENT

先建立账户结构，再看资金状态

把谁在管理、用哪台手机、哪个 OKX 钱包、哪些公开地址，逐级记录清楚。

1
第一步

创建负责人

负责人是资金和设备的归属人。比如张三、李四；系统会分别汇总他们名下的资产。

2
第二步

添加手机

为每台实际设备指定负责人。手机可以自由增加，不需要预先设定固定数量。

3
第三步

在手机内配置 OKX 钱包

点击手机行中的“查看钱包”即可展开该手机的钱包；每台手机默认有 3 个钱包，可按实际情况增加到 10 个。

4
第四步

导入公开地址

选择手机和钱包后导入地址。EVM 地址只需添加一次，即可覆盖已支持的多条 EVM 链。

5
完成后

在看板掌握资金状态

从总账户一路下钻到负责人、手机、钱包、地址和币种；看链/币种分布、净值变化和最新查询结果。

关于“实时”：系统会随机安排地址更新，也支持按全部账户、负责人、手机或钱包手动更新。看板显示的是最近一次成功查询到的链上状态。
自动发现资产：导入地址后系统会查询原生币和代币余额；系统稳定币无需逐个添加。对于索引服务或报价服务无法确认的资产，仍可在“添加自定义币种”中补充。
02

ACTIVITY MANAGEMENT

按钱包管理检查、活动和任务

活动模板创建一次，全账户的钱包都会出现对应项目；每个钱包独立填写自己的状态。

BUILT-IN

女巫检查

系统内置未登记、待检查、未发现风险、疑似女巫、已确认女巫五种状态。你可以在钱包资料中填写，并在钱包管理系统中筛选、统计和批量修改。

未登记待检查正常疑似确认

WALLET PROFILE

钱包资料

在手机列表展开钱包后，可以自定义钱包名称、钱包创建时间、判断依据和备注。创建时间和女巫状态都只是内部记录，不会触发任何链上操作。

GLOBAL TEMPLATE

自定义活动 / 任务

例如空投活动、交互任务或资格检查。每个模板可自定义下拉、勾选、日期、文本和数字字段，并定义哪些选项计为完成、进行中或风险。

你最终能看到女巫与自定义字段的全局统计

多少钱包待检查、疑似或已确认；每位负责人名下的检查情况；以及每个自定义字段的完成、进行中、风险和已填写数量。需要继续分析时，可导出 CSV。

03

COMMON TOOLS

需要时再使用的常用工具

这些功能补充资产识别、链配置、显示偏好和账户管理，不影响主流程。

◉

添加自定义 Token

输入合约地址或 Mint 地址，系统会识别名称、符号和精度。添加一次，即可扫描当前账户的全部匹配地址。

◇

导入自定义链

填写网络名称、Chain ID 和可信 HTTPS RPC。已导入的 EVM 地址会自动复用到新链。

↻

更新资产

自动更新采用随机计划；需要即时核对时，可以仅更新相关负责人、手机或钱包，减少无关查询。

◌

隐私与显示

右上角可隐藏金额，适合共享屏幕；字体可调为 90%、100%、115% 或 130%，偏好保存在本机。

✓
最后记住：系统只需要公开地址。

不要输入助记词、私钥、签名信息或 OKX 密码。自定义 RPC 请选择可信来源，导出 CSV 前确认接收对象。

CUSTOM EVM NETWORK

CUSTOM TOKEN

添加自定义币种

用于补充系统没有自动识别的 EVM 合约币或 Solana SPL 币。添加一次后，会扫描当前账户中该链的全部地址，以后新增地址也会自动纳入。

✓
全账户识别与自动报价

系统只读取公开链上余额，并优先采用流动性最高的 DEX 美元报价；找不到报价时显示“暂无报价”，也可以手动填写单价覆盖。

MANUAL SYNC

选择更新范围

日常自动更新会分散在一小时内执行。这里可以只更新需要查看的范围，减少不必要的查询。系统会优先使用代币索引服务，公共 RPC 仅作为后备。

↻
只读更新

更新只读取公开链上数据，不会签名或发送交易。
