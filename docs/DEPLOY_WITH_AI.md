# 使用 AI 在本机部署 Chainfolio

把下面的任务文本交给你信任的 AI 编程助手，并让它先阅读本文件：

> 请在我的电脑本地部署 Chainfolio。先检查 Docker 是否安装和运行，再检查 compose.yaml。服务只能监听 127.0.0.1:4173；不得上传、读取或展示 data、backups、.env 中的内容；不得修改其他 Docker 容器；不得开放路由器端口。执行前列出动作，部署后验证 /api/healthz，并告诉我首次创建本地主账户的方法。

AI 可以执行：

- 检查 Docker 和端口占用。
- 运行项目提供的启动、停止、备份和更新脚本。
- 查看不含用户数据的容器状态与错误日志。
- 验证 `http://127.0.0.1:4173/api/healthz`。

AI 不可以：

- 请求、读取或上传助记词、私钥、登录密码和 `data` 内容。
- 把端口绑定改为公网地址。
- 未经确认删除数据、备份、容器卷或其他项目。
- 把真实数据提交到 GitHub、Issue 或聊天。

完成标准：Docker 容器健康、本机页面可访问、首次运行显示“创建本地主账户”、重启后数据仍存在。
